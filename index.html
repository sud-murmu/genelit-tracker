How this tracker works

Your progress lives in a single file, progress.json, written by Colab into your Google Drive folder. This page watches that file and redraws itself whenever it changes.

  1. In Colab, run the tracker cell — it mounts Drive and writes progress.json into MyDrive/RAG_tracker/.
  2. Make sure that folder is synced to your computer with Google Drive for Desktop (so the file exists locally, e.g. G:\My Drive\RAG_tracker\progress.json).
  3. Click Connect progress file above and select that progress.json once.
  4. Edit the True/False flags in the Colab cell as you finish tasks and re-run it — this page updates automatically within a few seconds.

Note: live auto-refresh needs Chrome or Edge. In other browsers, use Connect to open the file manually to refresh.
